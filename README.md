# A Lenda das Quatro Estações

Um roguelike de ação em pixel art. Quatro reinos, quatro artefatos, e um reino
que foi engolido pela sombra antes de você chegar.

### ▶ [Jogar agora](https://filipesj1002.github.io/lenda-quatro-estacoes/)

Abre direto no navegador — computador ou celular. Não precisa instalar nada.

---

## Como jogar

No **computador**:

| | |
|---|---|
| `W` `A` `S` `D` | andar |
| mouse | mirar |
| botão esquerdo | atacar com a arma equipada — segure para repetir |
| botão direito | habilidade da classe (o escudo do Cavaleiro se segura) |
| `Espaço` | esquiva, com invulnerabilidade |
| `Q` `E` | habilidades |
| `F` | usar: baú, loja, fonte, portal |
| `I` `M` | inventário · mapa do andar |
| `G` | chamar o Aurelion, com o Juramento do Leão cheio |

No **celular**, joystick à esquerda, botões à direita. A mira acha o inimigo
mais perto sozinha.

**Dois jogadores** no mesmo teclado: o Aurelion entra com `Ctrl` direito e joga
nas setas. A lista completa está dentro do jogo, em *Controles*.

## Jogar sem internet, no celular

Dá para instalar como aplicativo e jogar em modo avião:

1. abra o endereço no **Safari** (no iPhone tem de ser o Safari) ou no
   **Chrome**, no Android;
2. **Compartilhar → Adicionar à Tela de Início**;
3. abra pelo ícone novo e **deixe a barra de carregamento terminar** — é nessa
   primeira vez que o jogo fica guardado no aparelho, então use Wi-Fi;
4. pronto: a partir daí abre sem internet.

## O jogo

Quatro reinos, cada um com sua estação, seu rei e seu artefato. A cada partida
as salas, os inimigos e os itens mudam de lugar. Morrer faz parte: você volta
com o que aprendeu, e com o que desbloqueou.

Tem quatro classes, cada uma com sua arma e seu jeito de lutar; dificuldades de
tranquila a **Morte Única**, onde não existe checkpoint — se morrer, acabou; um
mural de desafios; missões paralelas; e uma galeria que se preenche conforme
você descobre as coisas.

A ordem das estações começa pela estação de verdade, a do dia em que você
jogar.

E tem a DLC, **A Vingança das Sombras**, para quem terminar a história.
